# Mouth-placement cue cards

One image per sound — shown beside Coach Leo during the "watch me" moment to show
how the mouth/tongue makes the sound (like an SLP articulation card). If a file is
missing, the app shows a short **text cue** instead, so nothing breaks.

Filenames (uppercase sound code):
`R.png`, `S.png`, `L.png`, `K.png`, `G.png`, `F.png`, `SH.png`, `CH.png`, `TH.png`

Specs: clear mouth/tongue placement diagram, ~256×256, transparent or light
background. Best designed/validated by an SLP.

# Map art — drop the level-group screens here

`/map.html` auto-loads these (flat sky placeholder until each one exists).

Upload to **this folder** on the **`claude/dreamy-gauss-ywph11`** branch, named
**exactly** (lowercase, NO spaces):

- `academy.png`     → Levels 5–7 (your locked Academy screen)
- `levels1-4.png`   → Levels 1–4 (Starter Town)
- `levels8-10.png`  → Levels 8–10 (Champion's Arena)

9:16 vertical PNG, flat 2D vector style. Spaces in filenames break the path,
so it's `academy.png`, not `Academy .png`.

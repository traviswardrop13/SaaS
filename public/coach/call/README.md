# Full-body Leo for the video call

Drop these PNGs (transparent background) in this folder and the call upgrades
itself from the head icon to full-body talking Leo — no code change needed:

- `leo-open.png`   — full body, mouth OPEN  (required)
- `leo-closed.png` — full body, mouth CLOSED (required)
- `leo-idle.png`   — relaxed smile for when he's listening (optional)

Rules: SAME pose/size/position in every frame — only the mouth changes.
~1000px tall, PNG with transparency. The app swaps open/closed with his real
audio level, which reads as talking (the Duolingo 2-frame technique).

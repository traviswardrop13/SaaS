## Physical game contract

Each game registers `window.DailyAdventureGames[key]`. It uses the existing SayPlay hooks (`init`, `onWord`, `onHelp`, `pause`, `resume`, `reset`, `finale`, `destroy`). The player supplies `canvas#dailyCanvas`, `div#dailyControls`, `div#dailyBanner`, and `button#dailyHelp`.

If a controller supplies `sounds` and `soundMs`, pass those through as `G.sounds` and `G.soundMs` when calling `SayPlay.start(G)`. The existing engine then owns these sounds and their microphone quiet barrier. Do not introduce another audio context or player for the concert.

`init(api, moves)` receives the existing `done`, `practice`, `instruct`, `sfx`, `hint`, `cheer`, and `face` callbacks. Five moves selects the younger version; eight selects the older version. Only a completed physical objective calls `done`. A speech result enters `onWord` or `onHelp`; the game never creates a microphone, scores speech, changes targets, or writes clinical outcomes.

Help uses the current same-word speech turn. The game freezes while the player owns that turn. A successful turn grants the advertised mechanical help on the same physical objective. Cancellation, silence and backgrounding preserve the earned move and partial physical progress without granting the power. Pause freezes active timers, motion and delivery; it cancels held gestures safely.
